# Contributing

## Versioning Policy

SimpleMicrobiome uses the `MAJOR.MINOR.PATCH` version format.

- **MAJOR**: Incremented for incompatible changes to existing workflows, inputs, outputs, or core analysis behavior.
- **MINOR**: Incremented when a new analysis module, such as MaAsLin3, or a comparably distinct analysis capability is introduced.
- **PATCH**: Incremented for enhancements to existing modules, bug fixes, documentation updates, and interface refinements.

Versions must always use all three components, such as `v1.1.0` and `v1.1.5`. After a version is released, its number must not be reused or changed.
