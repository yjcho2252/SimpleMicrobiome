# Release v1.1.2 (2026-11-22)

- **Beta Diversity** adds PERMDISP, adjusted and unadjusted PERMANOVA comparisons on the same samples, and color overlays for alpha diversity or taxon abundance.
- **Read depth** is handled within each module. Jaccard automatically rarefies to the lowest selected depth. Taxa Bar Plot caps high-depth samples at 2,000 reads and retains lower-depth samples.
- **Plots** improve group markers, centroid labels, violin shapes, and significance annotations. Taxa Comparison can exclude outliers from the plot while testing the full data.
- **MaAsLin3** improves the Results Table and Association Detail layout and corrects the Beta coefficient legend intervals.

See the [user manual](../manual/README.md) for module settings.
