# Release 2026-07-31

## Summary

- Improved the reliability and repeatability of Docker dependency restoration.
- Added a persistent BuildKit cache for the pinned `renv` package environment.
- Added automatic retries for transient package repository or download failures.

## Changed

- Docker build (`Dockerfile`):
  - Enabled Dockerfile syntax version 1.7 for BuildKit cache mounts.
  - Added a persistent `renv` cache keyed to the R 4.5.1 environment.
  - Disabled cache symlinks so restored packages remain self-contained in the image library.
  - Consolidated dependency restoration into a retry-enabled build step.
  - Retries `install.R` up to five times with incremental delays when a transient installation failure occurs.
- Dependency installer (`install.R`):
  - Enabled non-interactive `renv` consent so dependency restoration can run unattended during Docker builds and scripted source installations.

## Notes

- This release changes the dependency-installation workflow only; it does not change the analytical methods or result calculations.
- Docker BuildKit is used for the persistent package cache and is enabled by default in current Docker Desktop and Docker Engine installations.
