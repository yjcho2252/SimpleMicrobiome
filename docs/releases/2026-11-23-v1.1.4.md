# Release v1.1.4 (2026-11-23)

- **Diversity navigation** now separates Alpha Diversity, Beta Diversity, and Constrained Ordination for a clearer analysis workflow.
- **Constrained Ordination** adds multivariable and conditioning models, aligned dbRDA distance options, and clearer taxa and environmental-variable controls.
- **Beta Diversity and Association** use a more focused layout, clearer variable selection, and improved stability. Correlation Heatmap is now named Association Heatmap.
- **Figure export** is standardized to 300 dpi for PNG downloads across analysis modules.

See the [user manual](../manual/README.md) for module guidance.
