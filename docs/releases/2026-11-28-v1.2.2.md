# Release v1.2.2 (2026-11-28)

- Preprocessing offers an adjustable per-sample read cap. It is off by default and starts at 100,000 reads when enabled.
- Core Taxa results and TSV exports include group mean relative abundance.
- Alpha Diversity adds index selection and within-subject pairing controls. Association Heatmap adds optional sample clustering within groups, and Core & Indicator Taxa has updated plot and result controls.
- Updated the user guide with separate pages for the Taxa Profiles modules and Core & Indicator Taxa.
