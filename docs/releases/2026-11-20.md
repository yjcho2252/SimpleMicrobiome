# Release v1.0 (2026-11-20)

## Added

- The first screen and the Citation tab now display the SimpleMicrobiome publication citation with a [journal article link](https://www.jmicrobiol.or.kr/journal/view.php?number=3102) and DOI `10.71150/jm.2606011`. The Citation tab lists analysis method references separately.
- Preprocessing now supports optional subsampling without replacement. The option is off by default. When enabled, its initial target is 10,000 reads per sample, and a fixed seed of 42 makes the draw reproducible. The settings apply when switching to an analysis tab. If any selected sample has too few reads, the app prompts the user to lower the target or deselect the affected samples.

## Documentation

- Updated the guide with the publication citation and the Preprocessing manual with subsampling instructions.
