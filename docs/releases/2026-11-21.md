# Release v1.1 (2026-11-21)

## MaAsLin3

- Added a dedicated Differential Abundance tab and pinned `maaslin3` 1.2.0 for the project's Bioconductor 3.22 environment.
- Added continuous and categorical primary predictors, explicit comparison groups and reference levels, and a 5% default prevalence filter.
- Added covariates, pairwise interactions, multiple random intercepts, input read depth adjustment, group tests, ordered contrasts, and matched strata. The left panel previews the selected model terms and analysis sample count.
- Added the package-generated coefficient and heatmap summary with PNG preview and PNG/PDF exports. Plot width, height, and font size can be changed without refitting the model.
- Added abundance and prevalence result views, individual and joint q-value filters, full TSV download, and paired sample-level association plots for ordinary main effects.

## MaAsLin2

- Added continuous primary predictors and the option to treat numeric codes as categorical groups. Continuous result views report the coefficient per unit of the predictor.
- Added a coefficient heatmap covering model terms and contrasts, with a selectable q-value threshold and clickable cells. The heatmap follows the plot dimensions and font controls, and the status panel appears below the plot.
- Added row-linked Association Detail with a boxplot and sample points for categorical contrasts, or a scatter plot for continuous predictors.

## Shared interface and documentation

- Categorical variables with more than 10 observed levels remain selectable and display a warning in both MaAsLin modules.
- Both modules apply their Plot Dimensions controls to Association Detail. MaAsLin3 divides the selected width across two panels.
- Standardized dropdown font sizes across modules and added the MaAsLin3 publication to the Citation tab.
- Updated the [MaAsLin2 manual](../manual/maaslin2.md) and added the [MaAsLin3 manual](../manual/maaslin3.md).
