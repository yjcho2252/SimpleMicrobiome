# Release v1.1.5 (2026-11-24)

- **Ordination displays** provide clearer taxa labels, explanatory-variable overlays, and optional group hulls.
- **Beta Diversity EnvFit** reports and displays taxa effect sizes and permutation p-values more consistently.
- **Differential abundance** uses aligned explanatory-variable terminology, and MaAsLin3 supports subgroup analysis with clearer status and waiting states.
- **Interface consistency** is improved through standardized display-section and module names.

See the [user manual](../manual/README.md) for module guidance.
