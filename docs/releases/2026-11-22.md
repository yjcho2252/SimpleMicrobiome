# Release v1.1.1 (2026-11-22)

- **Preprocessing** automatically uses the lowest selected read count when rarefaction is enabled. Taxa Barplot applies its own rarefaction to a maximum of 3,000 reads per sample.
- **Taxa Barplot** adds tooltips, clickable legend entries, automatic screen fitting, and an option to show all samples in one panel. Top N and abundance thresholds can use group means. The plot and TSV reuse the same calculations.
- **Alpha Diversity and Taxa Comparison** default to Violin plot, Dot Size 4, and Base Font Size 14. Both offer X-axis label rotation. Taxa Comparison also adds Jitter plot and improves violin readability across facets. New palettes are available in the taxa and diversity modules.
- **Differential Abundance** adds row-linked observed abundance, a forest plot, and a contrast heatmap to ANCOM-BC2. MaAsLin3 adds a two-panel volcano plot and a status panel. Numeric table values are displayed to two decimal places.
- **Networks** retain SparCC group panels when no edges pass the display cutoff. SparCC and SPIEC-EASI result tables display numeric values to two decimal places.
- **Documentation** includes the SimpleMicrobiome publication citation in the [project README](../../README.md#cite-simplemicrobiome) and updates the [user manual](../manual/README.md).
