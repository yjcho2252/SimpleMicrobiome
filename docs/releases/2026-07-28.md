# Release 2026-07-28

## Summary

- Added a reproducible R 4.5.1 installation and Docker build workflow based on pinned package versions in `renv.lock`.
- Made taxonomic-level selectors dataset-aware so unavailable ranks are not offered.
- Prevented plots, legends, tables, and status text from mixing results from a previous run with newly changed analysis settings.
- Improved SparCC and SPIEC-EASI handling of zero-edge networks, hub taxa, and network topology summaries.
- Documented the transformation and permutation settings used by Association Biplot.

## Added

- Reproducible environment files:
  - Added a root-level `Dockerfile` based on `rocker/shiny-verse:4.5.1`.
  - Added `renv.lock` with the tested CRAN, Bioconductor, and GitHub package versions.
  - Added Docker health-check and required Linux system libraries.

## Changed

- Installation and usage documentation:
  - Updated `install.R` to restore the tested dependency set from `renv.lock` and verify critical runtime packages.
  - Preserved compatible pinned versions and GitHub commits for dependencies including CVXR, ANCOMBC, SPRING, NetCoMi, and SpiecEasi.
  - Updated Docker pull/run and GitHub source-build instructions in `README.md`.
  - Standardized the documented R version and README badge to R 4.5.1.
  - Clarified when a Rust toolchain may be needed for packages installed outside the pinned environment.
- Taxonomic-level selection:
  - Updated Taxa Bar Plot, ANCOM-BC2, MaAsLin2, Random Forest, SparCC, SPIEC-EASI, Correlation Heatmap, and Association Biplot to offer only supported ranks present in the loaded taxonomy table.
  - Added validation messages for unavailable taxonomic ranks instead of allowing aggregation failures or unresponsive outputs.
- Run-dependent output consistency:
  - ANCOM-BC2, MaAsLin2, Random Forest, SparCC, SPIEC-EASI, Correlation Heatmap, and Association Biplot now retain the settings and data signature used for the completed run.
  - Changing analysis settings after a run now prompts the user to run the analysis again instead of updating only labels, legends, or selected output components around stale results.
  - Beta-diversity clustering and EnvFit overlays now detect changed settings and require the corresponding analysis to be rerun.
- Network analysis:
  - SparCC and SPIEC-EASI now treat a successfully estimated network with zero retained edges as a valid zero-edge result.
  - Fixed group assignment for empty edge tables.
  - Reworked hub scoring using degree, betweenness, and eigenvector centrality.
  - Added a modularity fallback using `igraph` when a finite value is unavailable from `NetCoMi::netAnalyze`.
  - Standardized connected-network titles to use `SPIEC-EASI`.
- Association Biplot:
  - Added the applied abundance transformation to the result status and figure legend.
  - Documented that dbRDA with Aitchison distance uses CLR-transformed abundances, whereas other dbRDA distances and CCA use TSS relative abundance.
  - Added the permutation count and initial random seed to the result status and figure legend.
  - Updated `docs/manual/association-biplot.md` accordingly.
- Example data:
  - Removed the SprockettTH subset's uninformative `Strain` column, whose 1,276 entries were all `Unclassified`.
- Minor UI:
  - Improved wrapping and alignment of Alpha Diversity plot download controls.

## Fixed

- Prevented absent or entirely uninformative taxonomy ranks from causing module failures or silent non-responses.
- Prevented stale analysis results from being presented with labels or legends derived from changed settings.
- Prevented SparCC group processing from failing when a valid group network contains no retained edges.
- Restored populated hub and topology summaries when network structure is available.
