# Release v1.2.0 (2026-11-26)

- **Taxa Bubble Plot** summarizes taxa abundance and prevalence by group. **Taxa Correlogram** shows pairwise taxon correlations, and **Upset Plot** compares which taxa are shared across groups.
- **Association Heatmap** adds sample-level abundance and detection views. Grouped views support significance annotations and filtering.
- **Analysis screens** use more consistent settings, palettes, waiting messages, and result cards. On larger screens, settings and results scroll independently.
- **Data Loading** accepts QZA feature and taxonomy files through the configured converter and supports Excel metadata.

See the [user manual](../manual/README.md) for module guidance.
