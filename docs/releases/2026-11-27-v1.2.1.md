# Release v1.2.1 (2026-11-27)

- **Diversity** puts exports in the settings panel. Beta Diversity switches between PCoA and NMDS there and shows result cards as analyses run. Alpha Diversity reports rarefaction depth in the figure legend.
- **Analysis screens** use more consistent download controls and axis labels. UpSet exposes its prevalence filter directly, and automatic analyses reuse results when inputs are unchanged.
- **User guide** adds navigation links and guidance for Taxa Bubble Plot, Taxa Correlogram, and UpSet Plot, with updated settings and defaults across several modules.

See the [user manual](../manual/README.md) for module guidance.
