# Release v1.1.3 (2026-11-23)

- **Plot order** can be configured in Preprocessing for samples and metadata group levels. Supported plots reuse the applied order for more consistent figures across modules.
- **Correlation Heatmap** adds selectable diverging palettes, more robust automatic color scaling, clearer cell boundaries, and refined legend placement.
- **Usability** improvements clarify shared ordering behavior and keep plot displays consistent without changing statistical results.

See the [user manual](../manual/README.md) for module settings.
