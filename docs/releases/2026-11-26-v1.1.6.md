# Release v1.1.6 (2026-11-26)

- **Association Heatmap** shows categorical subgroups in separate primary-group panels with a shared color scale and clearer significance markers.
- **Beta Diversity and Constrained Ordination** can connect pairs of samples from the same subject.
- **Taxa Barplot and Association Heatmap** default to automatic plot sizing and offer manual width and height controls.
- **Results and data loading** benefit from clearer figure legends, refined MaAsLin3 result views, and improved parsing of tabular inputs.

See the [user manual](../manual/README.md) for module guidance.
