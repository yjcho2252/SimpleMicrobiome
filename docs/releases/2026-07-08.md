# Release 2026-07-08

## Summary
- Added NMDS run metadata to Beta diversity results and plot descriptions.
- Made NMDS re-running clearer by renaming the action button to `Re-run NMDS`.
- Updated README local-use guidance to recommend the Docker image and keep source installation as the development-oriented path.

## Changed
- Beta diversity (`modules/mod_beta.R`):
  - Renamed the NMDS action button from `Redraw Plot` to `Re-run NMDS`.
  - Set NMDS ordination to use 2 dimensions and `trymax = 20`.
  - Added an `NMDS Run Details` result card showing the tool (`phyloseq::ordinate / vegan::metaMDS`), taxonomic level, distance metric, dimensions, final stress, starts, trymax, and convergence status.
  - Added the same NMDS run details to the plot description while the NMDS tab is active.
- README (`README.md`):
  - Changed the app description from end-to-end microbiome analysis to downstream microbiome analysis.
  - Expanded usage modes from two to three: hosted web app, Docker image, and source-code installation.
  - Added Docker image pull/run instructions for `mglab2252/simplemicrobiome:latest`.
  - Added alternate-port Docker guidance and Docker-specific troubleshooting text.
